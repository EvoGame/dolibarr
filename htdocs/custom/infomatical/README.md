# Infomatical

Infomatical enhancements to the Dolibarr Ticket module:

- **Plan my day** (Tickets menu): order the day's tickets with estimates and notes, see the total against
  the working day, carry unfinished tickets forward.
- **My ticket queue** (Tickets menu): open tickets assigned to the current user or on which they are an
  internal Ticket manager contact, most severe first.
- **AI tools** for the AI assistant and MCP server: list my open tickets, and (with user confirmation)
  assign, change status, change severity/progress, add a private note. The tools that change tickets need
  Dolibarr 25 or later; on Dolibarr 24 only the read tool is offered.

Requires Dolibarr 24.0 or later and the Ticket module.

Maintenance documentation is in `docs/`.
